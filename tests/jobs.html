Presenter notes What these scenarios demonstrate

The security heuristics are expected to score these examples 0, 45, and 100. The saved model produces its own ML score, so the final scores and colors depend on the actual predictions.

  1. Cisco pairs an official company domain with a matching recruiter email and ordinary recruitment language.
  2. Project Coordinator has an official application destination, but the Gmail recruiter address needs verification.
  3. Remote Payroll Assistant combines an HTTP IP address, a lookalike recruiter domain, an upfront payment request, and a banking password request.

When ML completes, Final = max(Security, ML). The higher component sets the score. If ML is unavailable, the panel clearly shows a security-only fallback. Model output is not a calibrated fraud probability, and green does not establish legitimacy.
